# Project Scope

## Project Name

Travel Agency Management System

## Project Description

Travel Agency Management System is a web application designed to help users explore travel destinations, browse travel packages, view weather information, and manage reservations through an intuitive platform.

## Main Objectives

* Allow users to register and log into the system.
* Allow users to browse destinations.
* Allow users to search travel packages.
* Display destination weather information.
* Allow users to create and manage reservations.
* Allow users to save favorite destinations.
* Allow users to view reservation history.

## Target Users

* Travelers
* Customers seeking travel packages
* Travel agency staff (optional)

## Technologies

* Frontend Web Application
* REST API
* Relational Database
* Docker
* External Weather API

## Initial Features

* User Registration
* User Login
* Destination Catalog
* Travel Package Catalog
* Weather Information
* Reservation System
* Favorites
* Reservation History

## Future Features

* Administration Panel
* Payment Integration
* Notifications
* Reviews and Ratings
