# System Architecture

## Components

The Travel Agency Management System will be composed of:

### Frontend

* HTML
* CSS
* JavaScript

Responsibilities:

* User Interface
* Reservation Forms
* Destination Search
* Authentication Screens

### Backend API

Technology:

* Java

Responsibilities:

* Authentication
* Reservation Management
* Destination Management
* Weather API Integration
* Database Communication

### Database

Technology:

* MySQL / MariaDB

Responsibilities:

* User Storage
* Reservations
* Travel Packages
* Destinations

### External API

Weather Service API

Responsibilities:

* Destination Weather Information

### Docker

Responsibilities:

* Containerization of services
* Service isolation
* Simplified deployment
